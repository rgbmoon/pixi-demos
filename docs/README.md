# docs/

Документация проекта **pixi-game**. Здесь живут **спецификации функционала** — по одной на модуль/фичу: назначение, бизнес-логика и принципы работы. Цель — прочитать спеку и понять модуль, не разбирая код построчно.

> Проект учебный. Спека отвечает на вопрос **«зачем и как это работает»**, а не «какие тут файлы». Код показывает *что* делает; спека — *почему так* и *по каким принципам*.

## Где что

- `specs/` — спецификации модулей (файл на модуль/фичу).
- `specs/_template.md` — шаблон новой спеки.

## Конвенция

- **Нейминг:** kebab-case по имени модуля/фичи — `background-canvas.md`, `slot-reels.md`, `event-emitter.md`.
- **Одна спека — один модуль/фича.** Фиксируй намерение, бизнес-правила, неочевидные решения и связи; не пересказывай очевидное из кода.
- **Актуальность:** меняешь поведение модуля — обнови его спеку в том же изменении. Спека, разошедшаяся с кодом, хуже её отсутствия.
- **Язык — русский** (как и весь проект).

## Как завести спеку

1. Скопируй [specs/_template.md](specs/_template.md) в `specs/<модуль>.md`.
2. Заполни разделы; неактуальные — удали, не оставляй заглушки.
3. Готовый образец формата — [specs/background-canvas.md](specs/background-canvas.md).
